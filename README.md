# 🍽️ Food App Backend

This is the **backend service** for the Full Stack Food App Assignment 2025.  
It is built with **Express.js**, **Sequelize ORM**, and **MySQL**, with **TypeScript** for type safety.  

The backend provides APIs for authentication, restaurants, menus, orders, and reporting.

---

## 🚀 Tech Stack
- **Framework**: Express.js  
- **Language**: TypeScript  
- **Database**: MySQL + Sequelize ORM  
- **Authentication**: JWT with rotating refresh tokens  
- **Validation**: Zod  
- **Linting & Formatting**: ESLint + Prettier
